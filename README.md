# TOURMATE

TOURMATE is a simple travel companion mobile app built with **React Native**.  
It helps users quickly find **Restaurants, Hotels, and Attractions** near their current location using the **Google Places API**.

---

## 🚀 Features
- **User Authentication** – Login & Sign-Up screen (integrated with database later).  
- **Home Page** – Clean UI with 3 main categories:  
  - Restaurants  
  - Hotels  
  - Attractions  
- **Search Functionality** – Search for any place directly by name.  
- **Location-based Results** – Fetches nearby options using the user’s current location.  
- **Detailed Listings** – Displays essential details like name, address, ratings, and images for each place.  

---

## 🛠️ Tech Stack
- **Frontend:** React Native  
- **Navigation:** React Navigation  
- **Authentication:** Firebase Authentication (planned)  
- **API:** Google Places API  
- **Database (future scope):** Firebase Firestore / Realtime Database  

---

## 📱 App Flow
1. **Login/Sign-Up Page**  
   - User creates an account or logs in.  

2. **Home Page**  
   - Displays 3 domain options: Restaurants, Hotels, Attractions.  
   - Includes a search bar for finding places directly.  

3. **Domain Pages (Restaurants/Hotels/Attractions)**  
   - Shows a list of places near the user’s location with relevant details.
